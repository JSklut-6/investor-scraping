WHAT IT DOES:
=============
1. ANALYZE PROPERTIES
   - Claude AI reviews property details
   - Calculates ROI, IRR, Cash-on-Cash returns
   - Generates investment recommendations
   - Extracts ideal investor criteria

2. MATCH INVESTORS
   - Machine learning recommendation engine
   - Learns from past successful matches
   - Scores investors 0-100% fit
   - Returns top 5 matches per property

3. AUTOMATE OUTREACH
   - Personalized email templates
   - Gmail API integration
   - Automatic follow-up sequences
   - Track engagement

4. TRACK PIPELINE
   - Google Sheets sync
   - CRM integration (Frappe/EspoCRM)
   - Deal stage tracking
   - Performance metrics

HOW TO USE:
===========
1. Upload to GitHub (see GITHUB_SETUP.md)
2. Install dependencies: pip install -r requirements.txt
3. Add API key to .env file
4. Run: python claude-analyzer/property_analyzer.py

PRODUCTION DEPLOYMENT:
======================
Option 1: Docker (Recommended)
  $ docker-compose up -d
  Access: http://localhost:8000 (API)
          http://localhost:5678 (n8n)

Option 2: Manual
  $ pip install -r requirements.txt
  $ python -m uvicorn api.main:app
